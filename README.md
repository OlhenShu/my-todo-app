### Практична робота №5: Робота з формами, керовані компоненти та маніпуляція станом у React

**Тема роботи:** Створення інтерактивних форм, обробка подій та динамічне оновлення списку даних у React.

**Мета роботи:** Отримати практичні навички створення керованих компонентів (controlled components), обробки подій відправки форми, валідації введених даних, а також реалізації функціоналу додавання та видалення елементів зі стану (state).

#### Основні досягнення в проєкті:

1.  **Керована форма додавання задач (`TodoInput`):**
    *   Використано хук `useState` для синхронізації значень полів введення (`input`, `select`) зі станом React.
    *   Реалізовано обробник `handleSubmit`, який запобігає перезавантаженню сторінки, валідує введений текст та створює новий об'єкт задачі.
    *   Після успішного додавання форма автоматично очищується та закривається.

2.  **Інтерактивний інтерфейс (Header + Main):**
    *   Кнопка "+ New Task" у хедері тепер функціональна: вона перемикає видимість форми додавання задачі.
    *   Реалізовано плавне керування станом відображення форми через `useState` у головному компоненті `App`.

3.  **Динамічне керування списком (CRUD):**
    *   **Додавання:** Нові задачі додаються до масиву `tasks` у головному компоненті `App` за допомогою оператора spread (`...`), що гарантує імутабельність стану.
    *   **Видалення:** Реалізовано функцію `removeTask`, яка видаляє задачу за її `id` за допомогою методу `filter()`.
    *   **Перемикання стану:** Додано можливість змінювати статус виконання (`done`) за допомогою методу `map()`.

4.  **Підтвердження дій (User Experience):**
    *   Перед видаленням задачі користувачеві виводиться діалогове вікно `confirm`, що запобігає випадковій втраті даних.

5.  **Розширена фільтрація та пріоритети:**
    *   Кожна задача має рівень пріоритету (`low` / `medium` / `high`), який візуально виділяється відповідним кольором.
    *   Збережено та вдосконалено систему фільтрів (Всі, Активні, Виконані), яка працює разом із новими функціями.

6.  **Сучасна стилізація та адаптивність:**
    *   Інтерфейс переведено на використання CSS-змінних (теми), що полегшує підтримку та зміну колірної схеми.
    *   Додано ефекти наведення (`hover`) та активні стани для кнопок, що робить додаток більш живим.

#### Архітектурна схема потоку даних:
`TodoInput` (введення) → `setTasks` → `App` (стан) → `TodoList` → `TodoItem` (відображення та видалення)
