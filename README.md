### Практична робота №7: Асинхронні запити та CRUD операції з API

**Тема роботи:** Завантаження, створення, оновлення та видалення даних через зовнішнє API в React.

**Мета роботи:** Навчитися використовувати хук `useEffect` та асинхронні функції для повної інтеграції з REST API (GET, POST, PATCH, DELETE), керувати станами завантаження та синхронізувати локальний стан із сервером.

#### Основні досягнення в цій роботі:

1.  **Повна інтеграція з DummyJSON API (CRUD):**
    *   **GET (Read):** Завантаження початкового списку задач при першому запуску (`/todos`).
    *   **POST (Create):** Додавання нової задачі на сервер (`/todos/add`).
    *   **PATCH/PUT (Update):** Синхронізація зміни статусу виконання (`done`) та тексту задачі з сервером.
    *   **DELETE (Delete):** Видалення задачі не тільки з локального стану, а й через API запит.

2.  **Асинхронна архітектура (`App.jsx`):**
    *   Логіку взаємодії з API винесено в окремі асинхронні функції (`addTask`, `updateTask`, `removeTask`).
    *   Реалізовано "Optimistic UI" або надійну обробку: локальний стан оновлюється миттєво або після успішної відповіді сервера.

3.  **Трансформація та мапінг даних:**
    *   ID для API-задач префіксуються (`api-ID`), що дозволяє коректно розрізняти їх та уникати конфліктів.
    *   Дані з API (`todo`, `completed`) автоматично мапляться у внутрішній формат (`title`, `done`).
    *   Призначається динамічний `priority` на основі статусу задачі.

4.  **Обробка помилок та станів:**
    *   Використання `try...catch` для кожного типу запиту.
    *   Вивід інформативних повідомлень про завантаження та помилки для покращення UX.

#### Технічний стек:
*   React Hooks (`useState`, `useEffect`)
*   Fetch API (async/await)
*   DummyJSON (External Mock API)
*   LocalStorage (Persistence fallback)

#### Попередньо реалізований функціонал:
*   Практична №6: `useEffect` для `localStorage`, Lazy Initializer.
*   Практична №5: Форми, керовані компоненти, CRUD операції.

#### Архітектурна схема потоку даних:
`External API` → `fetch()` → `Transform` → `App State` ↔ `localStorage`
`App State` → `Conditional Rendering` (Loading / Error / Content)
